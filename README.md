# पं. अवनीश मिश्र - वैदिक पंडित जी (Website & Portfolio)

वेदाचार्य पं. अवनीश मिश्र (स्वर्ण पदक विजेता) की आधिकारिक वैदिक कर्मकांड, महायज्ञ, पूजा एवं ज्योतिष परामर्श वेबसाइट।

## 🌟 प्रमुख विशेषताएँ (Key Features)

- **शास्त्रसम्मत एवं प्रामाणिक डिज़ाइन**: वैदिक केसरिया, स्वर्ण और कुमकुम रंगों का दिव्य संयोजन, शुभ ॐ एवं स्वस्तिक अलंकरण।
- **त्वरित कॉल एवं व्हाट्सएप बुकिंग**: 
  - एक क्लिक में सीधे कॉल करें (`+91 62608 76504`)
  - डायनामिक व्हाट्सएप बुकिंग फॉर्म जो यजमान का नाम, पूजा प्रकार, तिथि एवं स्थान प्री-फिल करके सीधे व्हाट्सएप चैट खोलता है।
- **विस्तृत सेवा सूची (Services Catalog)**:
  - गृह प्रवेश एवं वास्तु शांति पूजा
  - वैदिक विवाह संस्कार (16 संस्कार, सप्तपदी, कन्यादान)
  - श्री सत्यनारायण व्रत कथा
  - वैदिक हवन एवं महायज्ञ (महामृत्युंजय, नवग्रह शांति, लक्ष्मी हवन)
  - रुद्राभिषेक एवं शिव पूजन
  - संस्कार पूजाएँ (नामकरण, मुंडन, जनेऊ)
  - कालसर्प, मांगलिक एवं पितृ दोष निवारण
  - वैदिक जन्म कुंडली विश्लेषण एवं ज्योतिष परामर्श
- **पूजन सामग्री सूची (Interactive Samagri Checklist)**:
  - गृह प्रवेश, सत्यनारायण कथा, रुद्राभिषेक एवं हवन की प्रमाणित सामग्री सूची
  - चेकलिस्ट बॉक्स एवं एक क्लिक में पूरी सूची कॉपी करने की सुविधा।
- **यज्ञ एवं पूजा चित्रावली (Photo Gallery)**:
  - पोहरा देवी लक्षचंडी महायज्ञ (22,000 पंडितों के साथ यज्ञाचार्य)
  - नर्मदेश्वर तट पर शिव ध्यान एवं पारस शिवलिंग महापूजा
  - फुल-स्क्रीन लाइटबॉक्स (Next / Previous / Close) के साथ।
- **यजमान अनुभव एवं समीक्षाएं**:
  - नोएडा, गाजियाबाद, दिल्ली के यजमानों के सत्यापित अनुभव।
- **FAQ अनुभाग**:
  - अग्रिम बुकिंग, सामग्री व्यवस्था, सेवा क्षेत्र और मुहूर्त संबंधी प्रश्नों का समाधान।
- **स्थानीय SEO एवं Schema Markup**:
  - JSON-LD Structured Data (LocalBusiness, Priest) जो Google पर "Pandit in Noida", "Pandit in Ghaziabad", "Pandit near me" के लिए अनुकूलित है।
- **मोबाइल-फ्रेंडली**:
  - मोबाइल यूज़र्स के लिए नीचे फिक्स्ड 'कॉल', 'WhatsApp' और 'बुक करें' क्विक बार।

## 🚀 वेबसाइट कैसे खोलें (How to Run / View)

### विकल्प 1: सीधे ब्राउज़र में खोलें
`index.html` फ़ाइल पर डबल क्लिक करें अथवा टर्मिनल में रन करें:
```bash
open index.html
```

### विकल्प 2: लोकल सर्वर (यदि Node.js इन्स्टॉल्ड है)
```bash
npx serve .
# या
python3 -m http.server 8000
```
ब्राउज़र में `http://localhost:8000` या `http://localhost:3000` खोलें।

## 🌐 ऑनलाइन होस्टिंग (Deployment)
यह वेबसाइट 100% स्टेटिक और ज़ीरो-डिपेंडेंसी है। इसे मुफ्त में तुरंत लाइव किया जा सकता है:
- **Netlify**: फ़ोल्डर को [app.netlify.com/drop](https://app.netlify.com/drop) पर ड्रैग & ड्रॉप करें।
- **Vercel**: `vercel` कमांड से या GitHub कनेक्ट करके डिप्लॉय करें।
- **GitHub Pages**: रिपॉजिटरी की Settings > Pages में जाकर `main` ब्रांच सेलेक्ट करें।
